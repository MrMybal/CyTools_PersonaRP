Create persistent characters, worlds and relationships, then run roleplay conversations with local language models. Separate assistant conversations, images, translation and voice tools complement the character workflow.

## Main workflow {#workflow}

1. Install a supported language model and select its compute backend. Open or create a character and, when needed, its world.
2. Edit the character sheet, relationships and memory, then start a session. Inspect proposals before applying them to stored character data.
3. Use the Assistant workspace for a conversation outside roleplay. Install a voice engine separately when you want spoken dialogue or voice batches.

## Requirements and installation {#requirements}

Language models, image description and speech use separate compatible components. Choose a model that fits the selected CPU/GPU memory budget. Voice generation does not become available merely because a language model is loaded.

Read [Installation and models](doc:installation) for setup, the [User guide](doc:guide-lisez-moi) for detailed controls, and [Automation and API](doc:operations) for the public operation contracts.
